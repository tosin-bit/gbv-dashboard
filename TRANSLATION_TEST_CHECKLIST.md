## ✅ **What Should Translate:**

### **YES - Should Translate:**
✅ Navigation tab names  
✅ Page titles and headings  
✅ Button labels (Submit, Cancel, Save, etc.)  
✅ Form field labels  
✅ Status messages  
✅ Statistics card labels  
✅ Emergency banner  
✅ Help text  
✅ Error messages  
✅ Table headers  
✅ Chart labels  
✅ Action buttons  

### **NO - Should NOT Translate:**
❌ District names (official names)  
❌ Case numbers  
❌ Dates (format stays same)  
❌ Numbers (1, 2, 3, etc.)  
❌ Organization names (Rainbo, Police FSU)  
❌ Some technical terms (Analytics, Admin)  

---

## 🐛 **If Something Doesn't Translate:**

### **Check These:**

1. **Mutation Observer Working?**
   - New content should auto-translate
   - Wait 1-2 seconds after page loads

2. **Pattern Match Added?**
   - Check if phrase is in translation dictionary
   - Look in `language-switch.js`

3. **Browser Console:**
   - Open Developer Tools (F12)
   - Check for JavaScript errors
   - Look for translation system messages

4. **Refresh Page:**
   - Sometimes need to refresh after language change
   - Language preference is saved
