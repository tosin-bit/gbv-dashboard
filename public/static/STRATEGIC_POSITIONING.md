## 🔄 GBVIMS+ Data Can Flow INTO Your System (One-Way)

### How to Import GBVIMS+ Data (For Transition)

**If partners are currently using GBVIMS+, we make it EASY to move to your system:**

#### Step 1: Export from GBVIMS+
```bash
# GBVIMS+ has built-in CSV export
# Partner clicks: Reports → Export Cases → Download CSV
```

#### Step 2: Import to Your System (We Build This Tool)
```typescript
// /api/import/gbvims-data
app.post('/api/import/gbvims-data', async (c) => {
  const { env } = c;
  const csvFile = await c.req.formData();
  
  // Parse GBVIMS+ CSV format
  const gbvimsData = parseGBVIMScsv(csvFile);
  
  // Transform to your system's format
  for (const row of gbvimsData) {
    await env.DB.prepare(`
      INSERT INTO gbv_cases (
        case_number, incident_date, gbv_type_id, district_id,
        survivor_age_group, survivor_gender, case_status, 
        created_at, imported_from
      ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, 'GBVIMS+')
    `).bind(
      row.incident_id,
      row.date_of_incident,
      mapGBVtype(row.gbv_type),
      mapDistrict(row.district),
      row.age_group,
      row.sex,
      'reported',
      row.date_of_interview,
    ).run();
  }
  
  return c.json({ 
    success: true, 
    imported: gbvimsData.length,
    message: "All GBVIMS+ data successfully imported"
  });
});
```
